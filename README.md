## What is Version Control?
A system that tracks and manages changes in files over time.
## What is Git?
 A version control system used to track changes in code and files.
## What is GitHub?
An online platform for hosting and sharing Git repositories.
## What is Git Bash?
A command-line tool for running Git commands on Windows.
## What are the main parts of GitHub?
Repository, Branch, Commit, Pull Request, and Issues.
## What are the stages of Git/GitHub?
Working Directory → Staging Area → Local Repository → Remote Repository (GitHub).
